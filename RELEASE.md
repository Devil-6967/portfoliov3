# Devil Portfolio v1.0.20

Restored purple release with:

- sliding purple dock indicator;
- direction-aware page transitions;
- subtle heading settle motion;
- small card, tag, and dock micro-interactions;
- GPU-friendly transforms;
- reduced-motion accessibility;
- the full music library and persistent player behavior.

## Run locally

```powershell
npm install
npm run dev
```

## Deploy on Vercel

Import this directory as a Vite project. Vercel should detect:

- build command: `npm run build`
- output directory: `dist`
